Google Photos connection settings

To connect Google Photos, create a Google Cloud OAuth web client, enable Google Photos Picker API, and register your website's origin. Paste the public OAuth Client ID below. Never paste a client secret.

Connection checklist: Create a Google Cloud project, enable the Google Photos Picker API, configure the OAuth consent screen, add the Photos Picker read-only scope, and create a Web application OAuth client. Under Authorized JavaScript origins add your exact deployed HTTPS site origin (for example https://flourishing-kheer-1efe60.netlify.app, without a trailing slash). If the consent app is in Testing, add your Google account as a test user. Google Photos cannot be connected from a downloaded file:// or content:// HTML file.

Google Photos selection requires an internet connection and an authorized website origin. Only photos you select are imported. Photos and journals in this prototype remain local to this browser.
